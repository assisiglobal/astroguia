# Significados base (planetas, signos, casas, ángulos)

Esta tabla da la materia prima. La interpretación real surge de combinar planeta + signo + casa + aspectos en prosa propia, nunca concatenando estas frases sueltas.

## Planetas

| Planeta | Tema central |
|---|---|
| Sol | Identidad esencial, voluntad, propósito |
| Luna | Mundo emocional, necesidades de fondo, patrones heredados |
| Mercurio | Modo de pensar y comunicar, curiosidad |
| Venus | Modo de amar y disfrutar, valores, autoestima relacional |
| Marte | Impulso, deseo, asertividad |
| Júpiter | Expansión, sentido, fe, crecimiento |
| Saturno | Estructura, límite, responsabilidad, maduración |
| Urano | Individuación, ruptura, libertad, autenticidad |
| Neptuno | Disolución de límites, sensibilidad, idealización, espiritualidad |
| Plutón | Transformación profunda, poder, lo reprimido |

## Signos (cómo se expresa un planeta ahí)

| Signo | Modo de expresión |
|---|---|
| Aries | Directo, impulsivo, pionero |
| Tauro | Estable, sensorial, tenaz |
| Géminis | Versátil, curioso, verbal |
| Cáncer | Protector, sensible, ligado a la memoria y el vínculo |
| Leo | Expresivo, orgulloso, creativo |
| Virgo | Analítico, perfeccionista, orientado al servicio |
| Libra | Relacional, armonizador, estético |
| Escorpio | Intenso, profundo, busca verdad y control emocional |
| Sagitario | Expansivo, optimista, filosófico |
| Capricornio | Disciplinado, ambicioso, cauto |
| Acuario | Independiente, original, orientado a ideales colectivos |
| Piscis | Sensible, permeable, imaginativo |

## Casas

| Casa | Área |
|---|---|
| I | Identidad, imagen personal |
| II | Recursos propios, valores |
| III | Comunicación cotidiana, entorno cercano |
| IV | Hogar, raíces, familia de origen |
| V | Creatividad, romance, disfrute |
| VI | Trabajo cotidiano, rutina, salud |
| VII | Pareja, el otro como espejo |
| VIII | Intimidad profunda, recursos compartidos, transformación |
| IX | Viajes, extranjero, filosofía, estudios superiores |
| X | Vocación, carrera, imagen pública |
| XI | Amistades, grupos, proyectos a futuro |
| XII | Inconsciente, retiro, lo privado u oculto |

## Ángulos

| Ángulo | Qué describe | Área |
|---|---|---|
| Ascendente (ASC) | Cómo se muestra la persona al mundo | Personalidad propia |
| Medio Cielo (MC) | Vocación e imagen pública | Vida laboral y profesional |
| Descendente (DSC) | Qué se busca y proyecta en el otro | Amor y relaciones de pareja |
| Fondo de Cielo (IC) | Raíces y base emocional | Familia |

El signo de cada ángulo se lee con la tabla de signos de arriba.

## Regencias de signo

| Signo | Regente moderno | Regente tradicional |
|---|---|---|
| Aries | Marte | Marte |
| Tauro | Venus | Venus |
| Géminis | Mercurio | Mercurio |
| Cáncer | Luna | Luna |
| Leo | Sol | Sol |
| Virgo | Mercurio | Mercurio |
| Libra | Venus | Venus |
| Escorpio | Plutón | Marte |
| Sagitario | Júpiter | Júpiter |
| Capricornio | Saturno | Saturno |
| Acuario | Urano | Saturno |
| Piscis | Neptuno | Júpiter |

Usar el moderno como principal. El tradicional se suma como matiz cuando aporta (sobre todo en Escorpio, Acuario y Piscis).

## Cómo combinar

Fórmula base: planeta + signo (cómo se expresa) + casa (dónde se juega) + regente de la cúspide (hacia dónde conduce el tema) + aspectos de mayor peso. Integrar todo en prosa fluida, nunca como fórmula literal.
